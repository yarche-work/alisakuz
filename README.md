# Формула эксперта

Одностраничный сайт авторской системы, которая помогает собрать личность,
экспертность, позиционирование, контент, продукт и продвижение в цельную систему.

## Локальный запуск

Нужен Node.js 22 или новее.

```bash
npm ci
npm run dev
```

Vite выведет локальный адрес сайта в терминал.

## Проверка и сборка

```bash
npm test
npm run build
npm run preview
```

Готовая статическая версия появится в `dist/`. Пути к ресурсам относительные,
поэтому сборка подходит и для `username.github.io`, и для
`username.github.io/repository-name/`.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub.
2. Добавьте его как `origin` и отправьте ветку `main`.
3. В репозитории откройте **Settings → Pages** и выберите **GitHub Actions** в
   качестве источника публикации.

Workflow [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml)
проверит проект, соберёт сайт и опубликует `dist/` при каждом push в `main`.

## Структура

```text
assets/                  изображения и локальные шрифты
src/styles.css           стили страницы
test/                    автоматические проверки
index.html               точка входа
vite.config.js           настройки сборки
.github/workflows/       публикация на GitHub Pages
```

Проект не содержит лицензии на повторное использование контента и изображений.
